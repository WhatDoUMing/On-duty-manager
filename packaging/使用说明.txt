值日管家 0.1.0 · Windows 10/11 64 位

安装版
双击 DutyManager-Setup-0.1.0.exe，按向导安装。
安装时可选择“登录 Windows 后自动启动并在托盘提醒”，默认不勾选。

便携版
完整解压 DutyManager-Portable-0.1.0.zip，打开 DutyManager 文件夹，
双击 DutyManager.exe。请保留同目录的 _internal 文件夹。
目标电脑无需另装 Python。

首次设置
1. 在打开的浏览器页面中设置管理口令。
2. 添加成员，设置开始日期、起始值日生和拖地间隔。
3. 默认每天 22:00 通过 Windows 右下角系统通知提醒。
4. 关闭浏览器后托盘继续运行；右键托盘可打开管理或退出。

调整安排
“昨日忘做”会使今天继续由昨日值日生负责，后续轮值和拖地一起后移。
支持撤销误标、回家返校、临时换班，以及修改成员和提醒时间。
系统通知支持打开管理、十分钟后提醒、关闭本次。
通知横幅及声音遵循 Windows 的通知和勿扰设置。

手机管理
手机与电脑连接同一 Wi-Fi，在托盘或网页底部查看手机管理地址。
使用手机浏览器访问该地址并输入管理口令。
若未打开，检查 Windows 防火墙是否允许值日管家在专用网络通信。
电脑需保持开机；提醒仅在运行程序的电脑上显示。

数据与卸载
数据位于 %LOCALAPPDATA%\DutyManager。
关闭程序后可备份整个数据目录。升级和卸载会保留用户排班数据。
安装版可从 Windows“已安装的应用”卸载；卸载前先从托盘退出。
