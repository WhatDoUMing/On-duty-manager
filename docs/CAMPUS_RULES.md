# 校园版排班规则

校园版在 `codex/campus-duty` 分支维护。运行入口为 `run_campus.pyw`，
与原宿舍版使用不同数据目录、端口和应用标识。

每个区域单独轮换。个人模式按设定人数整批前进，组模式按组前进。
按周可使用连续七天的逻辑轮次，或固定周一交接的自然周。
每日均为排班日。自然周第一轮可是不足七天的初始化周。

小组处罚从记录次日起按 FIFO 执行；逻辑轮次暂停，自然周进度照常。
个人处罚额外加人，同人多笔处罚顺序计天，不同人同时执行。
处罚按日消耗，缺勤不自动延长；整组缺席保留原组并提示缺员。
仅取消尚未执行部分，撤销次日起停止处罚，已过去及当天的排班保留。

请假当天生效，返校次日起生效。个人模式返校者按操作先后优先，
全员离开暂停正常轮换。组模式不因请假而拆组或自动换组。
调班仅交换两个未来日期的正常任务。任务标识随逻辑顺延移动，
周轮换也只交换选定的两天。处罚任务通过撤销考核标记调整。

考核按事件日期计数，一次标记一次；小组和个人分别统计。
撤销排除考核计数并保留记录。人员交叉确认针对学生及两组的稳定标识，
新增交叉需要再次确认。
